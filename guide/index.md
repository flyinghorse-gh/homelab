# Self-Managed Homelab Guide

A beginner-friendly, chapter-by-chapter guide to building a home server that
runs a virtual OPNsense firewall on Ubuntu with KVM. It adapts FUTO's
[Introduction to a Self Managed Life](https://wiki.futo.org/index.php/Introduction_to_a_Self_Managed_Life:_a_13_hour_%26_28_minute_presentation_by_FUTO_software)
to a setup where the home router must keep working for the rest of the household.

!!! warning "Work in progress"
    Chapters are marked **outline**, **draft** or **verified**. Only follow
    chapters marked verified.

Start with [What you need](what-you-need.md) and the [Glossary](glossary.md),
then work through the chapters in order. Each chapter has a goal, steps,
a verification for every change, a rollback and an FAQ.

Values such as `<LAN_SUBNET>` or `<DUCKDNS_HOSTNAME>` are placeholders. Replace
them with your own. Never paste passwords, tokens or keys into notes you share.
